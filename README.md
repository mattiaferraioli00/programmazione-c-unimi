# C Programming – UniMi

Repository dedicated to collecting programming exercises completed during the **C Programming** course at the University of Milan.

## 🛠 Technologies

- **Language:** C
- **Standard:** C17
- **Compiler:** GCC
- **IDE:** CLion
- **Build System:** CMake

## 📂 Repository Structure

Exercises are organized by teaching unit and numbered sequentially.

```text
programmazione-c-unimi/
│
├── unit1/
│   ├── es1/
│   ├── es2/
│   └── es3/
│
├── unit2/
│   ├── es1/
│   ├── es2/
│   └── es3/
│
└── ...
```

Each exercise is independent and contains its own `main.c` file and CMake configuration.

## 🎯 Goals

- Master the fundamentals of C programming.
- Develop algorithmic thinking.
- Improve problem-solving skills.
- Apply theoretical concepts through practical exercises.

**University:** University of Milan (UniMi)
